## 🚀 O que o Mod Pack oferece?

✅ **FF13NovaFix:** Melhorias de compatibilidade, controles e gerenciamento de plugins.

✅ **Savior's Patch:** Correções relacionadas ao carregamento de texturas e à fluidez do jogo.

✅ **DXVK (Vulkan):** Alternativa de renderização que pode melhorar o desempenho e reduzir travamentos em sistemas compatíveis.

✅ **Patch 4GB:** Permite ao executável utilizar mais memória RAM, ajudando a evitar problemas relacionados ao limite de memória.

✅ **Gráficos e interface HD:** Melhorias visuais para elementos da interface, ícones e mapas.

## 🛠️ Como instalar? (Resumo rápido)

1. Instale o **Lightning Returns: Final Fantasy XIII** pela Steam e execute o jogo pelo menos uma vez.
2. Faça um backup dos arquivos originais e siga o vídeo para aplicar a tradução e o Patch 4GB.
3. Baixe o Mod Pack e extraia os arquivos na pasta principal do jogo, onde está localizado o `LRFF13.exe`.
4. Inicie o jogo e configure os mods conforme demonstrado no tutorial.
5. Nota:: se weiss_data tiver compactado extraia ele

**📁 Pasta padrão:**

`Steam\steamapps\common\LIGHTNING RETURNS FINAL FANTASY XIII\`
